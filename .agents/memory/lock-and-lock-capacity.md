name: Lock&Lock capacity decision
description: Facts and history of the Lock&Lock vershoudbakje capacity options
---
The Lock&Lock single glass container family offers 630 ml / 740 ml / 1 L options.
**Why:** The middle option is the true 740 ml model; an earlier spec asked for 750 ml but the user explicitly chose the real capacity. The user later supplied verified data (images, prices, links) for all three sizes and made 630 ml the default variant.
**How to apply:** Never round/normalize 740 ml to 750 ml. Treat the product data files as user-maintained truth — the user edits prices/defaults directly in the workspace; do not "restore" older defaults during refactors.
