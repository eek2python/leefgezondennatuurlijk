Implement high-impact SEO and performance improvements based on audit findings.

GOAL
Improve page speed, CTR, and SEO completeness without changing site structure.

==================================================
STEP 1 — Optimize images (HIGH PRIORITY)
==================================================

- Convert all images in:
  static/images/thumbnails/

to WebP format

Requirements:
- max width ~600px
- target size ≤ 80KB
- replace all .png/.jfif references with .webp
- remove .jfif usage entirely

==================================================
STEP 2 — Add lazy loading and dimensions
==================================================

For all <img> tags:
- add loading="lazy"
- add explicit width and height attributes

Apply to:
- category pages
- blog overview
- product pages
