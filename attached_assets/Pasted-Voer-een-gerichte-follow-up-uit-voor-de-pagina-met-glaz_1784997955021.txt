2. JAVASCRIPT: STICKY FILTERS
==================================================

Controleer eerst of het sticky filtergedrag al bestaat in:

- inline JavaScript in de template;
- een bestaand algemeen JavaScriptbestand;
- een bestaand pagina-specifiek bestand.

Gewenst gedrag:

- observeer `.storage-filters-sentinel`;
- voeg of verwijder `.is-stuck` op `.storage-filters-sticky`;
- gebruik `IntersectionObserver`;
- doe niets wanneer vereiste elementen ontbreken;
- veroorzaak geen JavaScriptfout in oudere browsers;
- initialiseer na DOMContentLoaded of gebruik een bestand met `defer`;
- initialiseer slechts één observer;
- voorkom dubbele eventlisteners.

Wanneer dezelfde functionaliteit al correct in een bestaand JavaScriptbestand
staat:

- maak geen nieuw bestand;
- behoud de huidige implementatie;
- rapporteer dat geen wijziging nodig was.

Wanneer inline JavaScript nog in de template staat en geen gelijkwaardige
externe implementatie bestaat:

- verplaats de functionaliteit naar een passend statisch bestand;
- gebruik bij voorkeur:
  `static/js/storage-filters.js`;
- verwijder alleen de bijbehorende inline code uit de template;
- laad het bestand met `{% static %}` en `defer`.

Gebruik qua gedrag bijvoorbeeld:

"use strict";

document.addEventListener("DOMContentLoaded", () => {
    const filterBar = document.querySelector(".storage-filters-sticky");
    const sentinel = document.querySelector(".storage-filters-sentinel");

    if (!filterBar || !sentinel || !("IntersectionObserver" in window)) {
        return;
    }

    if (filterBar.dataset.stickyInitialized === "true") {
        return;
    }

    filterBar.dataset.stickyInitialized = "true";

    const observer = new IntersectionObserver(
        ([entry]) => {
            filterBar.classList.toggle("is-stuck", !entry.isIntersecting);
        },
        { threshold: 0 }
    );

    observer.observe(sentinel);
});

Pas deze code aan de bestaande projectstijl aan.

==================================================

{

    "display_variant_id": display_variant.get("id") if display_variant else None,
    "affiliate_url": resolved_affiliate_url,
    "price": resolved_price,

    "capacity_display": ...,
    "total_display": ...,
    "size_display": ...,

Gebruik de bestaande helperarchitectuur en naamconventies.

Vul commerciële velden in deze volgorde:

1. displayvariantwaarde, wanneer aanwezig;
2. productniveau alleen wanneer het product geen varianten heeft;
3. geen fallback naar een andere variant.

Dus:

- een ontbrekende affiliate-link op de displayvariant mag niet stil
  terugvallen op de link van een andere variant;
- een prijs mag niet van een andere variant komen;
- beschikbaarheid mag niet van een andere variant komen;
- een algemene productlink mag alleen worden gebruikt voor een product zonder
  commerciële variantdata.
