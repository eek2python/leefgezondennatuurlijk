==================================================

Implement the selector with reusable vanilla JavaScript unless the project already uses another frontend framework for product variants.

The JavaScript must:

- support multiple product cards on one page;
- scope updates to the clicked product card;
- never rely on globally unique element IDs for repeated product cards;
- use `data-*` attributes or a JSON script block;
- attach behavior after `DOMContentLoaded`;
- fail gracefully when JavaScript is unavailable;
- avoid inline JavaScript event handlers;
- avoid injecting unsanitized HTML;
- update text using `textContent`;
- update URLs using validated data supplied by Django.

Suggested structure:

<div class="product-card"
     data-product-key="igluu_meal_prep_3delig">

    <div class="variant-selector"
         data-variant-selector>
        ...
    </div>

    <script type="application/json"
            class="product-variant-data">
        ...
    </script>
</div>

Alternatively use safely escaped data attributes if that matches the existing architecture better.

Use Django's safe JSON mechanism, preferably `json_script`, rather than manually marking arbitrary JSON as safe.
