Breid de bestaande Django-categoriepagina voor glazen vershoudbakjes uit met een herbruikbare formaatfilter.

De pagina heeft of krijgt al een hoofdselector voor:

- Enkel
- 3-delig
- 5-delig

Voeg daaronder een tweede selector toe:

- Alle
- Klein
- Middel
- Groot

De formaatfilter moet werken voor:

- losse vershoudbakjes;
- 3-delige sets;
- 5-delige sets;
- productfamilies met meerdere inhoudsmaten;
- producten met vormvarianten, zoals rond en vierkant;
- producten die nog het oude `capacity`-veld gebruiken.

==================================================
4. FORMAATCLASSIFICATIE
==================================================

Classificeer het praktische formaat op basis van het grootste bakje binnen de betreffende uitvoering of variant.

Gebruik aanvankelijk deze grenzen:

- Klein: grootste bak maximaal 600 ml
- Middel: grootste bak van 601 tot en met 1.200 ml
- Groot: grootste bak groter dan 1.200 ml

Maak deze grenzen centraal configureerbaar.

Gebruik bijvoorbeeld:

STORAGE_SIZE_THRESHOLDS = {
    "small_max_ml": 600,
    "medium_max_ml": 1200,
}

Gebruik interne sleutels:

- small
- medium
- large

Gebruik zichtbare Nederlandse labels:

STORAGE_SIZE_LABELS = {
    "small": "Klein",
    "medium": "Middel",
    "large": "Groot",
}

Maak een herbruikbare helper:

def classify_storage_size(capacities):
    """
    Classificeert een los bakje of set op basis van
    de grootste geldige capaciteit.
    """

    valid_capacities = [
        capacity
        for capacity in capacities or []
        if isinstance(capacity, (int, float)) and capacity > 0
    ]

    if not valid_capacities:
        return None

    largest_capacity_ml = max(valid_capacities)

    if largest_capacity_ml <= 600:
        return "small"

    if largest_capacity_ml <= 1200:
        return "medium"

    return "large"

Gebruik geen totale inhoud voor de formaatclassificatie.

Voorbeeld:

capacities = [400, 400, 400, 400, 400]

Totale inhoud:
2 L

Grootste bak:
400 ml

Classificatie:
Klein

Voorbeeld:

capacities = [400, 700, 1500]

Totale inhoud:
2,6 L

Grootste bak:
1,5 L

Classificatie:
Groot

6. LOSSE PRODUCTEN ZONDER VARIANTEN
==================================================

Voor producten zonder variants:

- gebruik `capacities` wanneer aanwezig;
- ondersteun een enkele waarde, bijvoorbeeld `[800]`;
- ondersteun tijdelijk het oude `capacity`-veld;
- gebruik bestaande normalisatielogica wanneer die al bestaat.

Voorbeeld:

"capacities": [800]

Classificatie:

Middel

Wanneer uitsluitend een oude tekstwaarde bestaat, bijvoorbeeld:

"capacity": "800 ml"

gebruik de bestaande backward-compatible parser wanneer aanwezig.

Maak geen kwetsbare nieuwe tekstparser wanneer de applicatie dit al elders heeft opgelost.

Wanneer de capaciteit niet betrouwbaar numeriek kan worden bepaald:

- toon het product bij “Alle”;
- toon het niet bij Klein, Middel of Groot;
- voeg intern een waarschuwing toe;
- laat de pagina niet crashen.

==================================================
7. PRODUCTFAMILIES MET MEERDERE VARIANTEN
==================================================

Een productfamilie kan meerdere inhouds- of vormvarianten hebben.

Bijvoorbeeld:

"variants": [
    {
        "id": "small",
        "shape": "Rechthoekig",
        "capacities": [450],
        ...
    },
    {
        "id": "medium",
        "shape": "Rechthoekig",
        "capacities": [1000],
        ...
    },
    {
        "id": "large",
        "shape": "Rechthoekig",
        "capacities": [1800],
        ...
    }
]

Dit product hoort dan bij:

- Klein;
- Middel;
- Groot.

Bereid daarom op productfamilieniveau voor:

size_categories = ["small", "medium", "large"]

Het product moet worden getoond wanneer minimaal één beschikbare variant bij het gekozen formaat past.

Maak een helper vergelijkbaar met:

def get_product_size_categories(product):
    """
    Geeft alle unieke formaatcategorieën terug waarin
    het product of een van zijn varianten verkrijgbaar is.
    """

Regels:

1. Heeft het product varianten met `capacities`, classificeer iedere variant.
2. Verwijder dubbele categorieën.
3. Sla varianten zonder geldige capaciteit over.
4. Heeft het product geen bruikbare varianten, gebruik de capaciteit op productniveau.
5. Behoud de logische volgorde:
   small, medium, large.

8. STANDAARDVARIANT BIJ EEN ACTIEVE FILTER
==================================================

Wanneer een productfamilie meerdere formaten bevat en de bezoeker bijvoorbeeld “Groot” selecteert:

- toon de productfamilie;
- selecteer bij de eerste weergave bij voorkeur een variant die onder Groot valt;
- gebruik niet automatisch een kleine standaardvariant terwijl de pagina op Groot is gefilterd.

Bereid hiervoor bijvoorbeeld voor:

matching_variant_id

en:

display_variant

Selectieregels:

1. Zoek beschikbare varianten die bij het actieve formaat passen.
2. Gebruik daarvan:
   - eerst de bestaande defaultvariant wanneer die passend is;
   - anders de eerste passende beschikbare variant.
3. Bij formaat “Alle”:
   - gebruik de gewone defaultvariant.
4. Wanneer geen passende variant bestaat:
   - toon de productfamilie niet binnen dat filter.

De productvariantselector binnen het productblok moet daarna gewoon blijven werken.

De bezoeker mag na het openen van het productblok ook naar een ander beschikbaar formaat wisselen.
