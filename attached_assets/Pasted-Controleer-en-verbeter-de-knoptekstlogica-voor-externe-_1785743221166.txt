Controleer en verbeter de knoptekstlogica voor externe productlinks.

Context
De productdata kan de volgende URL-velden bevatten:

- affiliate_url
- retailer_url
- official_url

Deze velden kunnen zowel op hoofdproductniveau als binnen `variants` voorkomen.

De URL-selectielogica gebruikt deze prioriteit:

1. affiliate_url
2. retailer_url
3. official_url
4. geen knop wanneer alle URL-velden leeg zijn

Bij producten met varianten geldt:

1. geselecteerde variant affiliate_url
2. geselecteerde variant retailer_url
3. geselecteerde variant official_url
4. hoofdproduct affiliate_url
5. hoofdproduct retailer_url
6. hoofdproduct official_url
7. geen knop

Nieuwe gewenste knoptekst voor bol.com
Wanneer de uiteindelijk geselecteerde URL begint met:

https://www.bol.com/nl/

moet de knoptekst altijd zijn:

"Bekijk prijs en reviews bij bol"

Dit geldt voor zowel:

- affiliate_url
- retailer_url

De knoptekst moet dus worden bepaald op basis van de URL die na toepassing van de volledige fallbacklogica daadwerkelijk wordt gebruikt.

Voorbeelden:

- affiliate_url =
  "https://www.bol.com/nl/nl/p/product/123/"
  → "Bekijk prijs en reviews bij bol"

- retailer_url =
  "https://www.bol.com/nl/nl/p/product/123/"
  → "Bekijk prijs en reviews bij bol"

- geselecteerde variant heeft een lege affiliate_url, maar een retailer_url
  naar bol.com
  → "Bekijk prijs en reviews bij bol"

- geselecteerde variant heeft geen URL en valt terug op een bol.com-URL
  van het hoofdproduct
  → "Bekijk prijs en reviews bij bol"

Standaardknopteksten
Gebruik voor overige URL’s voorlopig:

- affiliate_url:
  "Bekijk prijs en reviews"

- retailer_url:
  "Bekijk prijs en reviews"

- official_url:
  "Bekijk productspecificaties"

De bol.com-regel heeft voor affiliate_url en retailer_url voorrang op de
standaardknoptekst.

URL-detectie
Implementeer de detectie robuust.

Accepteer minimaal URL’s met deze host:

- www.bol.com

En met een pad dat begint met:

- /nl/

Controleer de URL bij voorkeur met URL-parsing in plaats van alleen met een
losse substringcontrole.

Een URL geldt als Nederlandse bol.com-productlink wanneer:

- hostname gelijk is aan `www.bol.com` of `bol.com`;
- pathname begint met `/nl/`.

https://bol.com.example.com/

Voorkeurslogica in Python
Centraliseer de bepaling van URL, linktype, knoptekst en rel-attribuut bij
voorkeur in één herbruikbare helper.

from urllib.parse import urlparse


def is_bol_nl_url(url):
    if not url or not isinstance(url, str):
        return False

    try:
        parsed = urlparse(url.strip())
    except (TypeError, ValueError):
        return False

    hostname = (parsed.hostname or "").lower().rstrip(".")
    path = parsed.path or ""

    return (
        hostname in {"bol.com", "www.bol.com"}
        and path.startswith("/nl/")
    )


def get_link_metadata(url, link_type):
    if not url:
        return None

    if (
        link_type in {"affiliate_url", "retailer_url"}
        and is_bol_nl_url(url)
    ):
        label = "Bekijk prijs en reviews bij bol"
    elif link_type == "affiliate_url":
        label = "Bekijk prijs en reviews"
    elif link_type == "retailer_url":
        label = "Bekijk prijs en reviews"
    elif link_type == "official_url":
        label = "Bekijk productspecificaties"
    else:
        return None

    rel_by_type = {
        "affiliate_url": "nofollow sponsored noopener",
        "retailer_url": "nofollow noopener",
        "official_url": "noopener",
    }

    return {
        "url": url,
        "type": link_type,
        "label": label,
        "rel": rel_by_type[link_type],
    }

Client-side variantselectie
Wanneer varianten via JavaScript worden geselecteerd:

geef per variant alle URL-velden of vooraf opgeloste linkmetadata mee;
laat de knop na iedere variantwissel opnieuw de juiste URL, tekst en
rel-waarde tonen;
pas ook de bol.com-detectie toe op de URL die na fallback daadwerkelijk
is geselecteerd;
voorkom dat de tekst van de vorige variant blijft staan;
voorkom dat een bol.com-knoptekst wordt gebruikt bij een niet-bol.com-URL.

Een variantobject kan bijvoorbeeld deze opgeloste velden bevatten:

{
  "resolved_url": "https://www.bol.com/nl/nl/p/product/123/",
  "resolved_url_type": "retailer_url",
  "resolved_label": "Bekijk prijs en reviews bij bol",
  "resolved_rel": "nofollow noopener"
}

Rel-attributen
Behoud de bestaande rel-logica:

affiliate_url:
rel="nofollow sponsored noopener"
retailer_url:
rel="nofollow noopener"
official_url:
rel="noopener"

De bol.com-knoptekst mag het linktype of het rel-attribuut niet veranderen.

Structured data
Verander geen JSON-LD-knoptekst, tenzij de huidige implementatie deze tekst
daar onterecht in opneemt. Structured data moet de URL zelf gebruiken en
niet afhankelijk zijn van de zichtbare knoptekst.

Uitvoering
Voer de wijziging direct door en rapporteer daarna:

welke bestanden zijn aangepast;
waar de knoptekst voorheen werd bepaald;
of er dubbele of afwijkende knoptekstlogica bestond;
hoe de bol.com-detectie nu werkt;
hoe dit bij varianten en fallback-URL’s werkt;
welke tests zijn toegevoegd of uitgevoerd;
of alle productkaarten, detailpagina’s en vergelijkingstabellen nu
dezelfde uitkomst geven.

Verander geen productdata en geen bestaande URL’s. Pas uitsluitend de
selectie- en presentatielogica voor URL’s en knopteksten aan.
